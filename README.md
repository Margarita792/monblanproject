# Monblan Project

This is a responsive one-page website built with **React**, **CSS Modules**, and **Flatpickr**.  
The project replicates the provided Figma design and demonstrates adaptive layout, datepicker integration, and dynamic card rendering.

---

## 🚀 Tech Stack
- **React 18**
- **CSS Modules**
- **Flatpickr** for custom datepicker
- **React Router DOM**
- **JavaScript (ES6+)**

## 🛠️ Installation and Setup

```bash

git clone https://github.com/Margarita792/monblanproject
cd monblanproject

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
